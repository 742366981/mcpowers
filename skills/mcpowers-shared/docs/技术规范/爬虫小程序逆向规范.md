# 爬虫小程序逆向规范

> **本文档定位**：本规范是《爬虫分析规范》v2.14.0 起拆分出的 **小程序与小游戏逆
> 向通用方法论册**，与 `mcpowers-reverse-miniprogram` 1:1 对应。
>
> - 抓包工具（开发者工具代理 / Charles / mitmproxy）见《爬虫工具与抓包规范》§1
> - 真实可用性验收见主《爬虫分析规范》§9.4
> - 跨端指纹交接见主《爬虫分析规范》§10.9

---

## §1. 包与运行时画像

小程序不是普通 H5。分析前记录**宿主平台、AppID/名称、宿主与基础库版本、普通
小程序或小游戏、主包/分包、登录态和授权目标**。

- **记录包来源、哈希、主包/分包关系、页面/组件、worker、WASM 和动态加载线索**
- **定位平台请求 API、项目封装层、拦截器、登录 code/session、动态参数和宿主注入值**
- 小游戏额外关注 game loop、worker、资源加载和 WASM / Native 能力边界
- **无法在授权范围内获取或分析资产时，保留阻塞说明，不绕过边界**

---

## §2. 平台差异

微信、支付宝、抖音、百度等宿主的**包格式、API 名称、登录态和开发者工具不同**。
先以当前平台实测证据建立方法，不得把微信术语或固定工具链无证据套到其他平台。

| 宿主 | 包格式 | 解包工具 | 开发者工具 |
|:-----|:-------|:---------|:---|
| **微信** | wxapkg | [unwxapkg](https://github.com/xxx/unwxapkg) / [wxappUnpacker](https://github.com/xxx/wxappUnpacker) | 微信开发者工具 |
| **支付宝** | amix / axml | 支付宝小程序开发者工具内置 | 支付宝小程序 IDE |
| **抖音** | 小程序包 | 抖音开发者工具 | 抖音开发者工具 |
| **百度** | swan-package | 百度开发者工具 | 百度开发者工具 |

**uni-app 跨端源码**：
- 编译为小程序时，最终运行载体按本规范处理
- 编译为 App 时，转入《爬虫Hybrid逆向规范》§1

## §3. 接口、算法与状态

通过**开发者工具、代理、授权运行环境或代码证据**触发真实业务动作：

- 接口清单标**来源**和**置信度**（Playwright / 开发者工具代理 /
  curl_cffi 实测）
- 至少 3 组输入对照**参数生成与响应**：
  - 记录 code / token
  - 记录宿主 session
  - 记录设备 / 版本
  - 记录分包加载的生命周期线索
- 实测后由 §3.0 验收交由主《爬虫分析规范》§9.4 做模块真实可用性验收

## §4. 调试资源所有权

> **外部接管资源不可关闭**（主《爬虫分析规范》§1.3 铁律的扩展示例）

小程序的外部资源列表：

| 资源 | origin / owner | 允许操作 | 收尾 |
|:-----|:---------------|:---------|:-----|
| 微信开发者工具 / 调试 IDE | `external/user` | attach、查看 Network、控制台 | 断开客户端；禁止 taskkill IDE |
| 调试浏览器（chrome inspect） | `external/user` | 复用 tabs、经确认操作 | 断开客户端；禁止关闭用户 Chrome |
| context / page | `external/user` | 复用 Cookie | 禁止 context.close() |
| 既有 page / tab | `external/user` | 经确认读取或操作 | 禁止 page.close() |
| 任务明确启动的隔离资源 | `task` | 仅在记录的授权范围内使用 | 按创建记录清理，不影响用户资源 |

**收尾验证**：结束客户端后重新探测开发者工具连接与原 tabs，**确认用户调试
环境、context 和既有 tabs 仍存活**。

## §5. 与工具册 / 主册的关系

### §5.1 真实可用性验收（指向主册 §9.4）

小程序模块的最终验收必须走主《爬虫分析规范》§9.4：
- 至少 3 组不同业务输入与真实请求对照
- 记录 code / token / 宿主 session / 设备 / 版本 / 分包加载
- `验收报告.md` 最终状态 = **`PASS`** 才算小程序模块可用

### §5.2 跨专项指纹交接（指向主册 §10.9）

小程序二级入口需产出 `01-目标画像/运行时指纹.md`，包含证据路径、
宿主、版本、核心逻辑候选层、置信度、主专项、辅助专项和未确认项。

### §5.3 uni-app 跨端来源

uni-app 源码编译为小程序时运行载体按本规范处理；编译为 App 时转入《爬虫Hybrid
逆向规范》。

## §6. 反模式

- ❌ 接管调试 IDE / WebView 后关闭 IDE（taskkill / 退出 IDE）
- ❌ 把微信术语无证据套到支付宝 / 抖音 / 百度
- ❌ 跳过开发者工具的合法授权直接反编译 wxapkg
- ❌ 把小程序与小游戏混为一谈（小游戏额外关注 worker / game loop）
- ❌ 在授权边界外强行获取代码或动态参数
- ❌ 实测少于 3 组不同输入就宣布算法还原成功
