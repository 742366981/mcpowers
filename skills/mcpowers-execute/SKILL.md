# mcpowers-execute（执行计划）

> 借鉴自 superpowers `executing-plans`。
> **核心**：严格按计划执行，不跑偏。遇到问题停下来问，不擅自改计划。

---

## 触发即执行

### 1. 加载计划
- 用户提供计划文件路径 → Read 该计划
- 用户没说 → 查找 `docs/计划/` 目录最新计划

### 2. 加载规范
- Read `mcpowers-shared/mcpowers-spec-index/SKILL.md`
- 加载相关规范（按计划涉及的技术栈）

### 3. 逐任务执行
对每个 Task：

1. **读任务细节**（目标、步骤、验证、commit）
2. **执行步骤**（按计划，不擅自加步骤）
3. **运行验证**（按计划写的验证方式）
4. **commit**（按计划写的 commit 信息）
5. **标记完成**（在计划文件里勾选 `[x]`）

### 4. 遇到问题的处理

| 情况 | 怎么处理 |
|:-----|:---------|
| 计划遗漏 | **停下来问用户**，不擅自补 |
| 计划有错 | **停下来问用户**，不擅自改计划 |
| 验证失败 | 调 `mcpowers-bugfix` 排查，再回来 |
| 任务依赖外部 | 等依赖完成，继续执行 |
| 范围蔓延 | 记录为后续任务，不在当前计划内做 |

### 5. 全部完成后
- 跑全量测试
- 跑全量 lint / type check
- 更新 README / 文档（如有变化）
- 整体 commit

---

## 反模式（禁止）

- ❌ 跳过验证步骤
- ❌ 不按计划擅自加任务
- ❌ 遇到问题不问，擅自改方案
- ❌ 多个任务合并成一个 commit
- ❌ 完成后不跑全量验证
