# 健康检查规范

本文档定义应用健康检查端点规范，确保 K8s/Supervisor/Nginx 等可正确感知服务状态。

> **核心原则**：**存活（Liveness）** 和 **就绪（Readiness）** 必须分离；**就绪检查必须验证依赖**

---

## 1. 三类端点（强制）

| 端点 | 用途 | 失败行为 | 检查内容 |
|:-----|:-----|:---------|:---------|
| `/health/live` | 存活探针（Liveness） | 杀容器 | 仅返回 200 |
| `/health/ready` | 就绪探针（Readiness） | 摘流量 | DB + Redis + 关键依赖 |
| `/health` | 综合健康（人/监控用） | - | live + ready + 业务指标 |

### 1.1 为什么必须分离

| 场景 | liveness 失败 | readiness 失败 |
|:-----|:--------------|----------------|
| DB 临时不可用 | 不杀容器（DB 恢复即可） | 摘流量（避免雪崩） |
| 内存泄漏 | 杀容器（重启可恢复） | 摘流量（重启窗口期） |
| 启动慢 | 不杀（仍在启动） | 摘流量（直到 ready） |

### 1.2 反模式

| ❌ 禁止 | 后果 |
|:--------|:-----|
| ❌ liveness 检查 DB | DB 抖动 → 容器被杀 → 服务雪崩 |
| ❌ readiness 不检查依赖 | 流量打到不健康实例 → 5xx |
| ❌ 单一 `/health` 端点 | K8s 无法区分探针语义 |

## 2. 实现（Flask 强制）

### 2.1 路由注册

```python
# apps/health/views.py

from flask import Blueprint, jsonify
from db.mysql.helpers import db
from db.redis.helpers import admin_redis
import time

health_bp = Blueprint('health', __name__)
_START_TIME = time.time()


@health_bp.route('/health/live', methods=['GET'])
def live():
    """Liveness Probe：仅返回 200，证明进程存活"""
    return jsonify({'status': 'alive'}), 200


@health_bp.route('/health/ready', methods=['GET'])
def ready():
    """Readiness Probe：检查 DB + Redis"""
    checks = {}

    # DB 检查
    try:
        db.session.execute(db.text('SELECT 1'))
        checks['database'] = 'ok'
    except Exception as e:
        checks['database'] = f'error: {str(e)[:100]}'

    # Redis 检查
    try:
        admin_redis.set('health_check', '1', ex=10)
        checks['redis'] = 'ok'
    except Exception as e:
        checks['redis'] = f'error: {str(e)[:100]}'

    all_ok = all(v == 'ok' for v in checks.values())
    status_code = 200 if all_ok else 503

    return jsonify({
        'status': 'ready' if all_ok else 'not_ready',
        'checks': checks,
    }), status_code


@health_bp.route('/health', methods=['GET'])
def health():
    """综合健康（供监控/人工使用）"""
    ready_resp, ready_code = ready()
    ready_data = ready_resp.get_json()

    return jsonify({
        'status': 'ok' if ready_code == 200 else 'degraded',
        'version': '1.0.0',
        'uptime_seconds': int(time.time() - _START_TIME),
        'checks': ready_data['checks'],
    }), ready_code
```

### 2.2 在 create_app 中注册

```python
# apps/__init__.py

from apps.health.views import health_bp


def create_app(protect_swagger=True):
    app = Flask(__name__)
    # ... 其他初始化 ...

    app.register_blueprint(health_bp)

    return app
```

### 2.3 跳过鉴权

```python
# utils/decorators.py

@app.before_request

    if request.path in EXEMPT_PATHS:
```

## 3. 响应规范（强制）

### 3.1 成功响应（200）

```json
{
  "status": "ok",
  "version": "1.0.0",
  "uptime_seconds": 3600,
  "checks": {
    "database": "ok",
    "redis": "ok"
  }
}
```

### 3.2 失败响应（503）

```json
{
  "status": "not_ready",
  "checks": {
    "database": "error: Can't connect to MySQL server",
    "redis": "ok"
  }
}
```

### 3.3 字段说明

| 字段 | 类型 | 说明 |
|:-----|:-----|:-----|
| `status` | string | `ok` / `degraded` / `not_ready` / `alive` / `ready` |
| `version` | string | 应用版本 |
| `uptime_seconds` | int | 进程启动时长（秒） |
| `checks` | object | 各依赖检查结果 |

## 4. K8s Probe 配置（推荐）

```yaml
# deployment.yaml
spec:
  containers:
  - name: flask-app
    image: flask-app:1.0.0
    livenessProbe:
      httpGet: { path: /health/live, port: 8000 }
      initialDelaySeconds: 30
      periodSeconds: 10
      timeoutSeconds: 3
      failureThreshold: 3
    readinessProbe:
      httpGet: { path: /health/ready, port: 8000 }
      initialDelaySeconds: 5
      periodSeconds: 5
      timeoutSeconds: 3
      failureThreshold: 2
    startupProbe:
      httpGet: { path: /health/live, port: 8000 }
      initialDelaySeconds: 10
      periodSeconds: 5
      failureThreshold: 30
```

## 7. ❌ 禁止（反模式）

| 禁止行为 | 后果 | 正确做法 |
|:---------|:-----|:---------|
| ❌ liveness 检查 DB | DB 抖动 → 雪崩 | liveness 仅返回 200 |
| ❌ readiness 跳过依赖检查 | 不健康实例接收流量 | 检查 DB + Redis |
| ❌ 在 health 端点暴露敏感信息 | 信息泄露 | 仅暴露 ok/error |
| ❌ 单一 /health 端点 | K8s 探针失效 | 拆分 live/ready |
| ❌ health 端点需要鉴权 | 探针调用失败 | 跳过鉴权 |
| ❌ health 检查包含慢操作 | 探针超时 | 仅做 ping 级别检查 |
