## 2. 容器化部署

### 2.1 Docker（通用）

#### Dockerfile 示例（Python）

```dockerfile
FROM python:3.13.3

WORKDIR /{项目名}

ADD ./requirements.txt /{项目名}

RUN python3 -m pip install -U pip -i https://mirrors.aliyun.com/pypi/simple

RUN pip3 install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple
```

**注意事项：**
- 基础镜像根据语言选择（Python/Java/Go 等）
- 使用国内镜像源加速安装
- 生产镜像应添加非 root 用户运行

### 2.2 Docker Compose（通用）

#### docker-compose.yml

```yaml
version: '2.1'
services:
  {项目名}:
    build:
      context: ./
      dockerfile: Dockerfile
    image: {项目名}
    container_name: {项目名}
    working_dir: /{项目名}
    restart: always
    ports:
      - '{端口}:{端口}'
    volumes:
      - ./{项目名}:/{项目名}
    environment:
        - TZ=Asia/Shanghai
    logging:
        driver: 'json-file'
        options:
          max-size: '100m'
          max-file: '2'
```

#### 启动命令

> **统一原则**：启动/重启/重部署都走 `up -d --force-recreate`（强制重建容器，确保新代码生效）。
> **只有在依赖变了（Dockerfile / requirements.txt 等）才加 `--build`**——`--build` 会重新构建镜像，docker compose 会自动检测到镜像变化并重建容器，无需额外加 `--force-recreate`。

```bash
# 启动/重启/重部署（默认命令）
docker-compose -f docker-compose.yml up -d --force-recreate

# 依赖变了才用
docker-compose -f docker-compose.yml up -d --build

# 查看日志
docker-compose -f docker-compose.yml logs -f

# 停止（容器仍在，可 start 重启）
docker-compose -f docker-compose.yml stop

# 删除（停止并清理容器、网络）
docker-compose -f docker-compose.yml down
```

> ❌ **禁止**：`docker-compose restart` / `docker-compose up -d`（不带 `--force-recreate`，新镜像/新代码可能不生效）。
> 详见 `开发环境规范.md §4.4`。

## 5. 反向代理（通用）

### 5.1 Nginx 配置

```nginx
server {
    listen 80;
    server_name example.com;

    location / {
        proxy_pass http://127.0.0.1:{端口};
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 7. 环境变量

### 7.1 常见环境变量（通用）

| 变量名 | 说明 | 示例 |
|:-------|:-----|:-----|
