# 安全规范

本文档定义项目安全防护规范，覆盖 OWASP Top 10 中后端常见风险。**当前以 Flask 后端（Python）+ Vue 前端为参考栈**；其他技术栈可参考通用原则，或生成对应技术栈的专属规范。

> **核心原则**：**纵深防御** —— 输入校验、输出编码、权限控制、敏感保护、限流降级 五层防护缺一不可

---

## 1. SQL 注入防护（强制）

### 1.1 参数化查询

```python
# ✅ 正确：参数化查询
db.session.execute(text("SELECT * FROM user WHERE id = :id"), {"id": user_id})

# ✅ ORM（推荐）
User.query.filter_by(id=user_id).first()

# ❌ 错误：字符串拼接
db.session.execute(text(f"SELECT * FROM user WHERE id = {user_id}"))
```

### 1.2 ORDER BY 白名单（强制）

```python
# ✅ 正确：白名单过滤
ALLOWED_SORT = {'create_time', 'update_time', 'id'}
sort_by = request.args.get('sort_by', 'create_time')
if sort_by not in ALLOWED_SORT:
    sort_by = 'create_time'
query = query.order_by(text(sort_by))

# ❌ 错误：直接拼接
query = query.order_by(text(request.args.get('sort_by')))
```

### 1.3 LIKE 查询转义

```python
# ✅ 正确：转义 % 和 _
def escape_like(s):
    return s.replace('\', '\\').replace('%', '\%').replace('_', '\_')
username = escape_like(request.args.get('username', ''))
query = query.filter(User.username.like(f'%{username}%'))
```

## 2. XSS 防护（强制）

### 2.1 输出编码策略

| 场景 | 策略 | 示例 |
|:-----|:-----|:-----|
| API JSON 响应 | 框架自动转义 | Flask `jsonify` 默认安全 |
| 前端 v-html | 禁止或 sanitize | 使用 DOMPurify.sanitize() |
| 文件下载 | Content-Disposition 强制 | 见 §6.2 |

### 2.2 前端 v-text 优先

```html
<!-- ✅ 正确：v-text 自动转义 -->
<div v-text="user.name"></div>

<!-- ❌ 危险：v-html 不转义 -->
<div v-html="user.name"></div>
```

## 4. 密码哈希（强制）

### 4.1 当前规范：MD5 + salt

> **安全建议**：MD5 已不推荐用于新项目；如需高安全场景，使用 `argon2-cffi` 或 `passlib[bcrypt]`。本规范保持 MD5 兼容历史项目，**生产环境强烈建议升级**。

```python
import hashlib
import secrets

def hash_password(password: str) -> str:
    """生成密码哈希（MD5 + 32位随机salt）"""
    salt = secrets.token_hex(16)  # 32字符
    return hashlib.md5((salt + password).encode()).hexdigest() + salt

def verify_password(password: str, hashed: str) -> bool:
    """验证密码"""
    salt = hashed[32:]
    return hashlib.md5((salt + password).encode()).hexdigest() == hashed[:32]
```

### 4.2 安全建议（推荐升级）

```python
# 推荐方案 1：argon2
from argon2 import PasswordHasher
ph = PasswordHasher()
hash = ph.hash(password)
ph.verify(hash, password)  # 验证

# 推荐方案 2：passlib + bcrypt
from passlib.hash import bcrypt
hash = bcrypt.hash(password)
bcrypt.verify(password, hash)
```

| 方案 | 安全性 | 性能 | 兼容性 |
|:-----|:------|:-----|:-------|
| MD5 + salt | ⚠️ 弱 | 🚀 快 | 旧项目 |
| bcrypt | ✅ 强 | ⚡ 中 | 新项目推荐 |
| argon2 | ✅✅ 很强 | ⚡ 中 | 新项目最佳 |

## 5. 敏感数据脱敏（强制）

> **本节为脱敏实现细节**。完整的全局敏感字段黑名单、脱敏规则、与日志封装的集成方式 → 见 `日志规范.md §5`（v2.6.0 起顶层规范）。
>
> **本节只保留 `mask_sensitive` 的递归脱敏实现**，作为安全工具函数供业务直接调用。

### 5.1 日志脱敏

```python
SENSITIVE_KEYS = {'password', 'token', 'secret', 'id_card', 'phone', 'bank_card'}

def mask_sensitive(data: dict) -> dict:
    """递归脱敏"""
    if isinstance(data, dict):
        return {k: ('***' if k in SENSITIVE_KEYS and v else v) for k, v in data.items()}
    if isinstance(data, list):
        return [mask_sensitive(item) for item in data]
    return data

logger.info(f'登录参数: {mask_sensitive(request.json)}')
```

### 5.2 响应脱敏（身份证/手机号/银行卡）

```python
import re

def mask_phone(phone):
    """手机号脱敏 138****1234"""
    return re.sub(r'(\d{3})\d{4}(\d{4})', r'\1****\2', phone)

def mask_id_card(id_card):
    """身份证脱敏 110***********1234"""
    return id_card[:3] + '*' * (len(id_card) - 7) + id_card[-4:]
```

## 6. 文件上传安全（强制）

### 6.1 校验清单

| 校验项 | 强制 | 示例 |
|:-------|:-----|:-----|
| 文件大小 | ✅ | `MAX_CONTENT_LENGTH = 10 * 1024 * 1024` |
| 文件扩展名 | ✅ | 白名单：`['jpg', 'png', 'pdf']` |
| MIME 类型 | ✅ | 双重校验（header + 实际内容） |
| 文件名清理 | ✅ | 移除 `../`、控制字符 |
| 存储路径 | ✅ | 非 webroot，使用独立文件域名 |

### 6.2 下载响应头

```python
from flask import send_file

def secure_download(file_path, download_name):
    response = send_file(file_path, as_attachment=True, download_name=download_name)
    response.headers['Content-Disposition'] = f'attachment; filename="{download_name}"'
    response.headers['X-Content-Type-Options'] = 'nosniff'
    return response
```

## 7. API 限流（强制）

### 7.1 限流策略

| 接口类型 | 建议 QPS | 工具 |
|:---------|:---------|:-----|
| 登录接口 | 5/min/IP | Flask-Limiter |
| 发送短信/邮件 | 1/min/手机号 | Redis 计数 |
| 列表查询 | 60/min/用户 | Flask-Limiter |
| 导出/导入 | 10/hour/用户 | Redis 计数 |
| 写操作 | 30/min/用户 | Flask-Limiter |

### 7.2 Flask-Limiter 示例

```python
from flask_limiter import Limiter
from flask_limiter.util import get_remote_address

limiter = Limiter(
    app=app,
    key_func=get_remote_address,
    storage_uri="redis://localhost:6379/0",
)

@app.route('/api/auth/login', methods=['POST'])
@limiter.limit("5 per minute")
def login():
    pass
```

## 8. 接口幂等性（强制）

### 8.1 Idempotency-Key 模式

```python
import redis

redis_client = redis.Redis(...)

def check_idempotency(key: str, ttl: int = 86400) -> bool:
    """SETNX 返回 True 表示首次请求，可继续处理"""
    return redis_client.set(f'idemp:{key}', '1', ex=ttl, nx=True)

@app.route('/api/order/create', methods=['POST'])
@require_idempotency_key  # 从 header 'Idempotency-Key' 读取
def create_order():
    idempotency_key = request.headers.get('Idempotency-Key')
    if not check_idempotency(idempotency_key):
        return api_error(msg='重复请求', code=409)
    # ... 创建订单逻辑
```

### 8.2 客户端使用

```javascript
// 前端生成 UUID
const idempotencyKey = `${userId}-${Date.now()}-${uuid()}`
fetch('/api/order/create', {
  headers: { 'Idempotency-Key': idempotencyKey }
})
```

## 9. ❌ 禁止（反模式）

| ❌ 禁止 | 后果 | 正确做法 |
|:--------|:-----|:---------|
| ❌ 字符串拼接 SQL | SQL 注入 | 参数化查询 |
| ❌ 信任 request.headers / cookies | 越权 | 鉴权后从 DB 重新查 |
| ❌ 日志打印明文密码/身份证 | 信息泄露 | mask_sensitive |
| ❌ 单一 MD5 无 salt | 彩虹表 | MD5 + 随机 salt |
| ❌ 用户上传文件存 webroot | RCE | 存独立文件服务 |
| ❌ 错误响应暴露堆栈 | 信息泄露 | 统一返回"服务器内部错误" |
| ❌ 限流只在边缘 | 内部接口被刷 | 关键接口全限流 |
