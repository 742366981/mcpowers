# mcpowers 仓库内部规范文档名清单（v4.3.0+ 智能二分判定权威源）
# 用途：行内注释/配置/swgger/docstring 含「参考/参见/详见/引用/按规范」等字眼
#   + 命中本清单任一 → 标记为「内部规范引用」→ 拦截
#   + 命中本清单任一别名 → 同样拦截（口语化引用）
#   + 既不命中本清单也不命中 _external_authority.txt → 视为画蛇添足 → 拦截
#
# 设计原则：
#   - 命中外部权威（_external_authority.txt）优先于本清单：合规技术引用放行
#   - 别名段不区分书名号、空格、横线（hook 自动规范化）
#   - CLAUDE.md / AGENTS.md / README.md / CHANGELOG.md 在路径白名单内放行
#
# 维护规则：
#   1. 增/删/重命名规范时必须同步更新本文件 + CLAUDE.md 必读段 + CHANGELOG.md Breaking Changes 段
#   2. 新增别名时必须能在 Read 实际定位到的规范里找到对应章节
#   3. 物理路径不写死（v2.27.3+ 注入物稳定性铁律）：本文件描述规范名，不绑定路径
#
# 共享给：scripts/check_no_ref_words.py + pre-write-check-no-ref-words.sh + post-write-check-no-ref-words.sh
