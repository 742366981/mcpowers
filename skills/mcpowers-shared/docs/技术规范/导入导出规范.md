# 导入导出规范

本文档定义通用的导入导出接口规范，适用于所有后端框架（Flask、Node.js、Go、Java 等）。

> **核心原则**：规范内容语言无关，代码示例仅作参考

---

## 1. 接口字段对照（强制）

### 1.1 操作类型与字段对照

| 操作 | id | name | code | xxx_name | xxx_code | status |
|:-----|:---|:-----|:-----|:---------|:---------|:-------|
| 列表返回 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 详情返回 | ✅ | ✅ | ✅ | ✅（按业务需要） | ✅（按业务需要） | ✅ |
| 创建/更新 | ❌ | ✅ | ✅ | ❌ | ❌ | ✅ |
| 删除（单个） | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ |
| 删除（批量） | ✅（数组） | ❌ | ❌ | ❌ | ❌ | ❌ |
| 导入 | ❌ | ✅ | ✅ | ✅（含义） | ✅（含义） | ✅（含义） |
| 导出 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

### 1.2 导入导出字段说明

| 列名类型 | 列表/详情返回 | 创建/更新 | 删除 | 导入填写 | 导出内容 |
|:---------|:--------------|:----------|:------|:---------|:---------|
| id | ✅ 主键id | ❌ 不需要 | ✅ 主键id | ❌ 不需要 | ✅ 主键id |
| name | ✅ 名称 | ✅ 名称 | ❌ 不需要 | ✅ 名称 | ✅ 名称 |
| code | ✅ 编码 | ✅ 编码 | ❌ 不需要 | ✅ 编码 | ✅ 编码 |
| xxx_name | ✅ 关联名称（按业务需要） | ❌ 不需要 | ❌ 不需要 | ✅ 含义，内部转id | ✅ 关联名称 |
| xxx_code | ✅ 关联编码（按业务需要） | ❌ 不需要 | ❌ 不需要 | ✅ 含义，内部转id | ✅ 关联编码 |
| status | ✅ 状态值 | ✅ 状态值 | ❌ 不需要 | ✅ "启用"/"禁用" | ✅ 状态值 |
| status_text | ✅ 状态文字 | ❌ 不需要 | ❌ 不需要 | ❌ 不需要 | ✅ 状态文字 |

### 1.3 导入规则

**导入参数格式 = 创建接口参数**，默认使用含义（name/code），无需 id：

| 列名 | 填写内容 | 内部处理 |
|:-----|:---------|:---------|
| name | "管理员" | 直接存储 |
| xxx_name | "管理员" | 自动转 xxx_id |
| xxx_code | "ADMIN" | 自动转 xxx_id |
| status | "启用" | 自动转 1，"禁用"转 0 |

### 1.4 导出规则

**默认导出字段 = 列表接口返回的字段**。基于导出模板的列名确定导出内容：

| 列名 | 导出内容 | 示例 |
|:-----|:---------|:-----|
| id | 主键 id | 1 |
| name | 名称字段 | "管理员" |
| code | 编码字段 | "ADMIN" |
| xxx_name | 关联名称 | "管理员" |
| xxx_code | 关联编码 | "ADMIN" |
| status_text | 状态文字 | "启用" |

## 5. 关联字段回填逻辑（强制）

关联字段指需要引用其他表ID的字段（如角色ID、部门ID）。通过列名特征自动识别匹配方式：

**识别规则**：

| 列名特征 | 匹配方式 | 说明 |
|:---------|:---------|:-----|
| 含"编码" | 查关联表的code字段 | 例：角色编码 → roles表code字段 |
| 含"名称" | 查关联表的name字段 | 例：角色名称 → roles表name字段 |
| 含"ID" | 直接使用填写值 | 例：角色ID → 直接作为ID |
| 其他 | 按关联表配置查找 | 默认规则 |

**完整流程**：

```
┌─────────────────────────────────────┐
│ 1. 获取模板数据                      │
│    - 列名：模板文件的表头           │
│    - 值：用户填写的单元格内容        │
└─────────────────┬───────────────────┘
                  ▼
┌─────────────────────────────────────┐
│ 2. 识别字段类型                      │
│    - 列名含"编码"→ 编码类型         │
│    - 列名含"名称"→ 名称类型         │
│    - 列名含"ID" → 直接使用         │
│    - 其他→ 按关联表配置查找         │
└─────────────────┬───────────────────┘
                  ▼
┌─────────────────────────────────────┐
│ 3. 匹配查找                          │
│    编码类型：查关联表的code字段       │
│    名称类型：查关联表的name字段       │
│    直接使用：值作为最终ID            │
│    无匹配→ 报错该行                  │
└─────────────────┬───────────────────┘
                  ▼
┌─────────────────────────────────────┐
│ 4. 回填关联ID                       │
│    例：roles表code="ADMIN"→id=1     │
│    回填role_id=1                    │
└─────────────────────────────────────┘
```

**示例**：

| 模板列名 | 模板填写值 | 关联表字段 | 查找结果 | 回填值 |
|:---------|:-----------|:-----------|:---------|:-------|
| 角色编码 | ADMIN | code | id=1 | role_id=1 |
| 角色名称 | 管理员 | name | id=1 | role_id=1 |
| 角色ID | 1 | - | - | role_id=1 |
| 部门编码 | DEPT01 | code | id=5 | dept_id=5 |

## 8. 导入逻辑流程（强制）

**步骤**：
1. 检查文件存在和格式
2. 读取文件表头，映射到字段名
3. 逐行校验（必填/格式/是-否转换）
4. 关联字段回填（按列名特征自动识别）
5. 唯一性校验（重复则失败）
6. 事务提交
7. 返回结果（成功数/失败数/错误详情）

> 📝 **导入逻辑Python示例参考（Flask 框架）**
```python
from flask import request
from openpyxl import load_workbook

from db.mysql.helpers import db           # SQLAlchemy 实例（详见 数据库规范.md）
from db.mysql.models.role import Role     # 数据模型（项目实际路径）
from utils.responses import api_success, api_error  # 统一响应


@bp.route('/import', methods=['POST'])
def import_data():
    """导入数据接口（详见本规范第 7 节 docstring）"""
    # 1. 获取文件
    if 'file' not in request.files:
        return api_error(400, '请上传文件')
    file = request.files['file']
    if not file.filename.endswith(('.xlsx', '.csv')):
        return api_error(400, '仅支持.xlsx或.csv格式')

    # 2. 读取文件（Excel/CSV）
    wb = load_workbook(file)
    ws = wb.active
    rows = list(ws.iter_rows(values_only=True))

    # 3. 解析表头映射
    headers = [str(cell).strip() if cell else '' for cell in rows[0]]
    header_map = {'角色编码': 'role_code', '角色名称': 'role_name', '是否启用': 'status'}

    # 4. 逐行处理
    success_count = 0
    fail_count = 0
    errors = []

    for i, row in enumerate(rows[1:], start=2):
        try:
            row_data = dict(zip(headers, row))
            field_data = {}
            for header, value in row_data.items():
                if header in header_map:
                    field_name = header_map[header]
                    if field_name == 'status':
                        field_data[field_name] = 1 if value == '是' else 0
                    else:
                        field_data[field_name] = value

            # 5. 关联字段回填（按列名特征自动识别已在步骤3处理）
            # 6. 唯一性校验：默认重复则失败（策略详见本规范第 14 章）
            role_code = field_data.get('role_code')
            existing = Role.query.filter_by(role_code=role_code).first()
            if existing:
                raise Exception(f'角色编码{role_code}已存在')
            role = Role(**field_data)
            db.session.add(role)
            success_count += 1
        except Exception as e:
            fail_count += 1
            errors.append({'row': i, 'message': str(e)})
            db.session.rollback()  # 单行失败回滚该事务

    db.session.commit()
    return api_success({
        'total': success_count + fail_count,
        'success': success_count,
        'fail': fail_count,
        'errors': errors[:10]
    }, '导入完成')
```

## 10. 导出逻辑流程（强制）

**步骤**：
1. 获取查询条件
2. 构建查询（支持单选/多选/范围查询）
3. 执行查询
4. 构建文件（导出列=模板列）
5. 返回文件下载

> 📝 **导出逻辑Python示例参考**
```python
# 模块顶部导入区
from io import BytesIO

from flask import make_response
from openpyxl import Workbook


@bp.route('/export', methods=['GET'])
def export_data():
    # 1. 构建查询
    query = Role.query
    if status := request.args.get('status'):
        query = query.filter(Role.status == int(status))
    if role_ids := request.args.get('role_ids'):
        id_list = [int(x) for x in role_ids.split(',') if x.strip().isdigit()]
        if id_list:
            query = query.filter(Role.id.in_(id_list))
    roles = query.all()

    # 2. 构建文件（Excel/CSV）
    wb = Workbook()
    ws = wb.active
    ws.title = '角色数据'
    headers = ['角色编码', '角色名称', '是否启用', '创建时间']
    ws.append(headers)
    for role in roles:
        ws.append([
            role.role_code, role.role_name,
            '是' if role.status == 1 else '否',
            role.create_time.strftime('%Y-%m-%d %H:%M:%S') if role.create_time else ''
        ])

    # 3. 返回文件
    output = BytesIO()
    wb.save(output)
    output.seek(0)
    response = make_response(output.getvalue())
    response.headers['Content-Type'] = 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
    response.headers['Content-Disposition'] = 'attachment; filename=role_export.{ext}'
    return response
```

## 11. 模板下载接口（强制）

提供标准化模板下载，确保用户使用正确格式。

**模板结构要求**：
1. 第1行：表头（带批注）
2. 第2行：合并单元格的提示行（★★★ 以下所有行均为示例数据，导入前请全部删除此提示行及以下数据 ★★★）
3. 第3行起：示例数据

> 📝 **模板下载Python示例参考**
```python
# 模块顶部导入区
from io import BytesIO

from openpyxl import Workbook
from openpyxl.comments import Comment
from openpyxl.styles import Alignment


@bp.route('/template/download', methods=['GET'])
def download_template():
    wb = Workbook()
    ws = wb.active
    ws.title = '角色导入模板'

    # 第1行：表头
    headers = ['角色编码', '角色名称', '是否启用']
    ws.append(headers)
    for col, header in enumerate(headers, start=1):
        cell = ws.cell(row=1, column=col)
        # 表头样式：居中、加粗
        cell.alignment = Alignment(horizontal='center', vertical='center')
        # 批注
        cell.comment = Comment(
            '类型：字符串\n示例：admin\n校验：长度6-20位\n必填：必填',
            '系统'
        )

    # 第2行：合并单元格的提示行
    ws.merge_cells(start_row=2, start_column=1, end_row=2, end_column=len(headers))
    hint_cell = ws.cell(row=2, column=1)
    hint_cell.value = '★★★ 以下所有行均为示例数据，导入前请全部删除此提示行及以下数据 ★★★'
    hint_cell.alignment = Alignment(horizontal='center', vertical='center')

    # 第3行起：示例数据
    ws.append(['ADMIN', '管理员', '是'])

    output = BytesIO()
    wb.save(output)
    output.seek(0)
    response = make_response(output.getvalue())
    response.headers['Content-Type'] = 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
    response.headers['Content-Disposition'] = 'attachment; filename=role_template.{ext}'
    return response
```

## 13. 大文件异步任务（强制）

> ⚠️ **触发条件**：单次导入/导出数据 **> 1000 行** 时，**必须**走异步任务

### 13.1 为什么需要异步

| 数据量 | 同步处理 | 异步任务 |
|:------|:---------|:---------|
| < 500 行 | ✅ 1-3 秒可完成 | 不需要 |
| 500-1000 行 | ⚠️ 接近超时阈值 | 建议异步 |
| > 1000 行 | ❌ 必然超时 | **必须异步** |

### 13.2 异步导入流程

```
1. 前端 POST /import → 后端创建 import_task → 立即返回 task_id
2. 后端异步执行：解析 → 校验 → 写入 → 更新 task 状态
3. 前端轮询 GET /import/task/{task_id}/status → 展示进度
4. 完成后 GET /import/task/{task_id}/result → 下载错误报告
```

### 13.3 异步接口规范

**创建导入任务**：

```python

Content-Type: multipart/form-data

参数：
  - file: file（必填）

响应：

  "code": 0,
```

### 13.4 异步导出（流式生成）

> **大文件导出推荐**：服务器端流式生成文件，HTTP 响应使用 chunked transfer encoding

```python
from flask import Response, stream_with_context
import csv
import io

@bp.route('/export-large', methods=['GET'])
def export_large():
    """流式导出（百万级数据）"""
    def generate():
        # 第一行：表头
        yield '﻿' + ','.join(['id', 'name', 'create_time']) + '\n'

        # 逐行查询 + 输出
        for row in db.session.query(Role).yield_per(1000):
            yield ','.join([str(row.id), row.name, row.create_time.isoformat()]) + '\n'

    return Response(
        stream_with_context(generate()),
        mimetype='text/csv',
        headers={'Content-Disposition': 'attachment; filename=role_export.csv'}
    )
```

- Key 格式：`{prefix}:import_task:{task_id}` → JSON

## 14. 判重策略配置（强制）

> **三种策略**（按需选择，在接口 docstring 中声明）

| 策略 | 行为 | 适用场景 |
|:-----|:-----|:---------|
| **失败（默认）** | 重复则该行失败，整体不中断 | 严格数据准确性 |
| **覆盖** | 重复则更新原记录 | 数据修正场景 |
| **跳过** | 重复则静默跳过 | 全量同步场景 |

**配置方式**（接口 docstring 中声明）：

```python
@bp.route('/import', methods=['POST'])
def import_data():
    """导入数据
---
tags:
  - 角色管理
summary: 批量导入角色
description: |
  重复角色编码时**跳过**该行，不影响其他行导入。
  唯一性字段：role_code（角色编码）。
parameters:
  - in: formData
    name: file
    type: file
    required: true
    description: 文件(.xlsx/.csv)
responses:
  200:
    description: 导入结果
    examples:
      application/json:
        code: 0
        data:
          total: 100
          success: 95
          fail: 5
          skipped: 0
          errors:
            - row: 3
              message: "第3行角色编码 ADMIN 已存在，已跳过"
        msg: "导入完成"
"""
```

**错误信息模板**（必须包含）：

| 信息组成 | 示例 |
|:---------|:-----|
| 字段名 | "角色编码" |
| 填写的值 | "ADMIN" |
| 已有值（如果可获取） | "已存在记录：管理员 (id=1)" |
| 处理动作 | "已失败 / 已覆盖 / 已跳过" |

**示例**："第3行角色编码 'ADMIN' 已存在记录（id=1），已跳过"

## 16. ❌ 禁止（反模式）

| 禁止行为 | 后果 | 正确做法 |
|:---------|:-----|:---------|
| ❌ 禁止根据 name 模糊匹配回填 ID | 误匹配、数据污染 | 仅按 code/id 精确匹配 |
| ❌ 禁止导出时写入密码/手机号/身份证 | 信息泄露 | 字段白名单 + 脱敏 |
| ❌ 禁止直接读取超大文件到内存 | OOM | 流式读取 + 分批提交 |
| ❌ 禁止忽略必填校验 | 数据不完整 | 必填字段先校验再处理 |
| ❌ 禁止单行失败中断整个导入 | 体验差 | try/except + 累计错误 |
| ❌ 禁止导入时硬编码关联表字段 | 维护成本高 | 配置化（详见 §5 关联字段） |
| ❌ 禁止导出文件名带特殊字符 | 文件名乱码 | ASCII + 日期（`{module}_export_20240101.xlsx`） |
| ❌ 禁止模板使用 xls 格式（旧版） | 兼容性问题 | 仅使用 .xlsx |
