# 代码同步修改规范

本文档定义代码变更时需要同步更新的内容，确保代码和文档的一致性。

---

## 1. 变更类型分类（强制）

| 变更类型 | 说明 | 影响范围 |
|:---------|:-----|:---------|
| 模型变更 | 数据库表结构修改 | 模型文件、视图docstring、验证逻辑 |
| 逻辑变更 | 接口业务逻辑修改 | 视图docstring、模型注释 |
| 路径变更 | API路径或路由修改 | 蓝图注册、视图docstring |
| 配置变更 | 配置文件修改 | 所有引用该配置的地方 |
| 新增接口 | 新建API接口 | 模型、视图docstring、蓝图注册 |
| 删除接口 | 删除API接口 | 视图、蓝图注册 |

---

## 2. 模型变更同步（强制）

### 2.1 变更类型与同步项（强制）

| 变更类型 | 必须同步更新的文件 |
|:---------|:------------------|
| 新增字段 | 模型文件、视图docstring 参数定义 |
| 删除字段 | 模型文件、视图docstring 参数定义 |
| 字段类型变更 | 模型文件、视图docstring 参数定义 |
| 字段注释变更 | 模型文件、视图docstring 参数描述 |
| 唯一约束变更 | 视图docstring 参数定义 |
| 索引变更 | 视图docstring 参数定义 |

### 2.2 检查清单（强制）

- [ ] 字段名是否正确
- [ ] 字段类型是否正确
- [ ] 字段注释是否与业务一致
- [ ] 唯一约束是否正确
- [ ] 索引是否正确
- [ ] 外键是否使用普通 INT（无外键约束）
- [ ] 时间字段默认值是否正确
- [ ] create_user/update_user 是否存在

---

## 3. 逻辑变更同步（强制）

### 3.1 变更类型与同步项（强制）

| 变更类型 | 必须同步更新的文件 |
|:---------|:------------------|
| 新增参数校验 | 视图docstring 参数定义 |
| 删除参数校验 | 视图docstring 参数定义 |
| 参数校验规则变更 | 视图docstring 参数定义 |
| 权限变更 | 视图docstring security 定义 |
| 业务规则变更 | 视图docstring description |

### 3.2 检查清单（强制）

- [ ] 参数校验是否完整
- [ ] 必填参数是否有检查
- [ ] 参数类型是否正确转换
- [ ] 权限装饰器是否正确
- [ ] 错误码是否正确返回
- [ ] 创建人/更新人是否正确填充

---

## 4. 路径变更同步（强制）

### 4.1 变更类型与同步项（强制）

| 变更类型 | 必须同步更新的文件 |
|:---------|:------------------|
| 路径重命名 | 蓝图注册、视图docstring |
| 路由方法变更 | 视图docstring HTTP method |
| 路径参数变更 | 视图docstring 参数定义 |

---

## 5. 配置变更同步（强制）

### 5.1 变更类型与同步项（强制）

| 变更类型 | 必须同步更新的文件 |
|:---------|:------------------|
| 新增配置项 | 所有使用该配置的地方 |
| 配置项删除 | 所有引用该配置的地方 |
| 配置项值变更 | 相关业务逻辑 |

---

## 6. 询问模板（强制）

当用户要求修改时，使用以下模板确认：

```markdown
## 修改方案

### 1. 变更内容
- 文件：
- 变更类型：
- 影响范围：

### 2. 同步更新
- [ ] 模型文件：
- [ ] 视图docstring：
- [ ] 蓝图注册：
- [ ] 其他相关文件：

### 3. 确认事项
- [ ] 变更是否符合预期？
- [ ] 是否需要同步更新其他文件？
- [ ] 是否需要更新文档？

请确认后我再执行修改。
```

---

## 7. 审查要点（强制）

### 7.1 自查问题（强制）

1. 这个变更会影响哪些接口？
2. 影响的接口的视图docstring 是否同步更新？
3. 模型文件的字段定义是否与视图docstring 一致？
4. 参数校验逻辑是否与视图docstring 一致？
5. 创建人/更新人是否正确填充？

### 7.2 禁止行为（强制）

- ❌ 只修改模型文件，不更新视图docstring
- ❌ 只修改逻辑，不更新模型注释
- ❌ 只修改视图docstring，不同步模型
- ❌ 只修改代码，不更新文档
