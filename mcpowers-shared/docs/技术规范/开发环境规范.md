# 开发环境规范

本文档定义项目开发环境的标准初始化流程。

---

## 1. 项目初始化流程（强制）

### 1.1 初始化检查清单

每个新项目创建时，必须按顺序执行：

| 步骤 | 操作 | 说明 |
|:-----|:-----|:-----|
| 1 | 创建 .gitignore | 根据项目类型自动识别并创建 |
| 2 | 创建语言特定文件 | 如 requirements.txt 等 |
| 3 | 创建虚拟环境脚本 | 如 venv_windows.bat |
| 4 | 创建环境配置示例 | 如 .env.example |
| 5 | 更新记忆文件 | 记录虚拟环境路径 |

## 3. Python 项目规范（强制）

### 3.1 必须文件

| 文件 | 说明 |
|:-----|:-----|
| requirements.txt | Linux/macOS 依赖 |
| requirements_windows.txt | Windows 依赖 |
| venv_windows.bat | Windows 虚拟环境创建脚本 |

### 3.2 requirements.txt 格式

```
# 依赖包
flask==3.0.0
flask-cors==4.0.0
flask-compress==1.14
flask-migrate==4.0.5
flask-sqlalchemy==3.1.1
pymysql==1.1.0
redis==5.0.1
python-dotenv==1.0.0
pyyaml==6.0.1
```

### 3.3 venv_windows.bat

```bat
@echo off
REM 创建 Python 虚拟环境

echo 创建虚拟环境...
python -m pip install -U pip
python -m venv ../venv/{项目名}-env

echo 激活虚拟环境...
cd ../venv/{项目名}-env/Scripts
call activate

echo 升级 pip...
python -m pip install -U pip

echo 安装依赖...
python -m pip install -r ../../../{项目名}/requirements_windows.txt

echo.
echo 完成！激活命令：cd ../venv/{项目名}-env/Scripts && activate
pause
```

## 0. 速查表（每次任务前必须对照）

### 强制执行项
- [ ] **修改前**：必须先分析影响、询问确认
- [ ] **完成时**：必须立即 commit
- [ ] **接口开发**：必须先写 docstring，再写实现
- [ ] **代码注释**：函数/类/复杂逻辑必须有完整注释
- [ ] **临时文件**：必须放在 `temp/` 目录，用完即删
- [ ] **细节记录**：用户告知关键信息时，必须立即记录到 `docs/细节记录/`

### 禁止项
- ❌ 未经确认直接修改任何代码/文档
- ❌ 先写代码后补文档
- ❌ 只 commit 代码不 commit 文档
- ❌ 在项目目录创建临时文件

## 5. 虚拟环境路径管理（强制）

### 4.1 路径规范（强制）

**虚拟环境统一放在项目平级的 `venv/{项目名}-env` 目录**：

```
workspace/
├── venv/
│   └── {项目名}-env/
│       ├── Scripts/          ← Windows
│       └── bin/              ← Unix
└── {项目名}/
    ├── apps/
    └── ...
```

**路径格式**：
- Windows：`../venv/{项目名}-env/Scripts/python`
- Unix：`../venv/{项目名}-env/bin/python`

## 5. 执行检查清单（强制）

### 5.1 每次工作前检查（强制）

| 检查项 | 操作 | 如果异常 |
|:-------|:-----|:---------|
| 虚拟环境是否存在 | 检查虚拟环境可执行文件是否存在 | 提示用户创建 |
| 依赖是否完整 | 检查依赖列表是否完整 | 提示用户安装依赖 |

**Windows 路径命令格式规范**：
> 路径必须用双引号包起来，参数放在引号外面，用空格分隔
> - ✅ `"../venv/xxx/Scripts/python" --version`
> - ❌ `"../venv/xxx/Scripts/python --version"` （参数被包进引号）
