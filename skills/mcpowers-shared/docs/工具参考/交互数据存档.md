# 交互数据存档

记录接口的请求/响应数据，方便调试和快速对接。

---

## 1. 功能说明

**解决的问题**：
- 多端对接时（后端与后端、后端与算法、后端与爬虫等），可以直接查看真实交互数据
- 方便调试和排查问题
- 交接项目时，别人可以通过存档快速了解交互格式

**记录类型**：

| 类型 | 说明 |
|:-----|:-----|
| request | 请求数据 |
| response | 响应数据 |
| callback | 回调数据 |

---

## 2. 存储结构

```
项目/
└── temp/
    └── interaction/              # 交互数据存档
        └── {任务ID或时间戳}/
            ├── request_xxx.json
            └── response_xxx.json
```

## 3. 参考实现

```python
# utils/interaction_saver.py

import os
import json
import shutil
from datetime import datetime
from utils.loggings import general_log as logger
from db.redis import admin_redis
from common.settings import config


def _get_interaction_dir():
    """获取交互数据存储目录"""
    base_dir = '/项目路径/temp/interaction'
    return base_dir


def _cleanup_old_interactions(max_tasks=10):
    """清理旧的交互数据目录（超过max_tasks个时，删除最早的）

    使用Redis分布式锁确保多worker环境下只有一个执行清理
    """
    try:
        lock_key = '项目前缀:interaction:cleanup:lock'
        acquired, release_lock = admin_redis.atomic_lock_with_watchdog(lock_key, ex=60)
        if not acquired:
            return

        try:
            base_dir = _get_interaction_dir()
            if not os.path.exists(base_dir):
                return

            # 获取所有任务目录
            task_dirs = [d for d in os.listdir(base_dir) if d.startswith('task')]
            if len(task_dirs) <= max_tasks:
                return

            # 按修改时间排序
            dirs_with_mtime = []
            for d in task_dirs:
                dir_path = os.path.join(base_dir, d)
                try:
                    mtime = os.path.getmtime(dir_path)
                    dirs_with_mtime.append((mtime, dir_path))
                except Exception:
                    continue

            dirs_with_mtime.sort()
            dirs_to_delete = dirs_with_mtime[:len(task_dirs) - max_tasks]

            for mtime, dir_path in dirs_to_delete:
                shutil.rmtree(dir_path)
                logger.save_critical(f'[InteractionSaver] 清理旧交互数据: {dir_path}')
        finally:
            release_lock()
    except Exception:
        pass


def save_interaction(task_id, data_type, source, path, data):
    """保存交互数据到JSON文件

    Args:
        task_id: 任务ID
        data_type: 数据类型（request/response/callback）
        source: 来源（algorithm/spider）
        path: 接口路径
        data: 原始数据（dict）
    """
    try:
        # 检查开关
        try:
            debug_save = config.get('debug', 'debug_save_interaction').lower() == 'true'
        except Exception:
            debug_save = False
        if not debug_save:
            return

        # 生成文件名
        timestamp = datetime.now().strftime('%Y%m%d_%H%M%S_%f')
        # 清理路径中的特殊字符
        path_clean = path.strip('/').replace('/', '_').replace('-', '_')
        filename = f"{timestamp}_{data_type}_{source}_{path_clean}.json"
        dir_path = os.path.join(_get_interaction_dir(), f'task{task_id}')

        # 创建目录
        os.makedirs(dir_path, exist_ok=True)

        # 保存文件
        file_path = os.path.join(dir_path, filename)
        with open(file_path, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)

        # 清理旧数据（超过10个任务目录时删除最早的）
        _cleanup_old_interactions(max_tasks=10)
    except Exception as e:
        logger.save_critical(f'[InteractionSaver] 保存交互数据失败: {str(e)}')
```

## 4. 配置说明

| 配置项 | 说明 |
|:-------|:-----|
| `debug_save_interaction` | 开关，生产环境设为 false |
| `max_tasks` | 保留最近任务数，默认 10 |
| `lock_key` | 分布式锁键名 |

**在需要记录的地方调用**：

# 保存请求

    task_id=123,
    data_type='request',

## 6. 注意事项

| 事项 | 说明 |
|:-----|:-----|
| 生产环境 | 必须关闭开关，避免大量写入 |
| 敏感数据 | 存档中可能包含敏感信息，交接时需注意 |
| 磁盘空间 | 定期检查，避免占用过多磁盘 |
