# mcpowers 文档/代码/配置禁用引用字眼清单
# 权威源：v4.0.1+ 接口零引用 + v4.0.2+ 文档零引用 + v4.3.0+ 代码/配置零引用（智能二分）
# 设计动机：
#   注释/配置应聚焦"当前怎么做 / 怎么对接调用"，不应含指向其他文档的字眼——
#   这些字眼会让读者以为还要再去查其他文档才能用。
#   代码注释/配置文件的读者正是接手这份代码的下一个工程师，
#   他在 IDE 里看到"参考规范"会困惑：到底是哪个规范？我点哪里看？
#
# 使用方式：
#   - Python:  open(this).read().splitlines() → 过滤空行 + # 注释
#   - Shell:   grep -v '^#' this | grep -v '^$'
#   - 路径解析：通过 ${CLAUDE_PLUGIN_ROOT} 定位（hooks 唯一允许环境变量场景）
#
# 单一权威源；scripts/check_no_ref_words.py / swagger-lint-helper.py /
#   export_docs.py / post-write-check-no-ref-words.sh / pre-write-check-no-ref-words.sh
#   五处共用（v4.3.0 起扩展到代码/配置/dockstring 扫描）
# 增删字眼必须同步更新五处脚本与 CLAUDE.md 必读段

#   ❌ # 参考《代码规范》§11.3     → 内部规范（命中 → 拦截）

#   ❌ # 按规范要求校验             → 口语化（命中"按规范要求" → 拦截）
