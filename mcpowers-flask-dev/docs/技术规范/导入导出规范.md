# 导入导出规范

本文档定义通用的导入导出接口规范，适用于所有后端框架。

> **核心原则**：规范内容语言无关，代码示例仅作参考

---

## 1. 接口字段对照（强制）

### 1.1 操作类型与字段对照

| 操作 | id | name | code | xxx_name | xxx_code | status |
|:-----|:---|:-----|:-----|:---------|:---------|:-------|
| 列表返回 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 详情返回 | ✅ | ✅ | ✅ | ✅（按业务需要） | ✅（按业务需要） | ✅ |
| 创建/更新 | ❌ | ✅ | ✅ | ❌ | ❌ | ✅ |
| 删除（单个） | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ |
| 删除（批量） | ✅（数组） | ❌ | ❌ | ❌ | ❌ | ❌ |
| 导入 | ❌ | ✅ | ✅ | ✅（含义） | ✅（含义） | ✅（含义） |
| 导出 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

### 1.2 导入导出字段说明

| 列名类型 | 列表/详情返回 | 创建/更新 | 删除 | 导入填写 | 导出内容 |
|:---------|:--------------|:----------|:------|:---------|:---------|
| id | ✅ 主键id | ❌ 不需要 | ✅ 主键id | ❌ 不需要 | ✅ 主键id |
| name | ✅ 名称 | ✅ 名称 | ❌ 不需要 | ✅ 名称 | ✅ 名称 |
| code | ✅ 编码 | ✅ 编码 | ❌ 不需要 | ✅ 编码 | ✅ 编码 |
| xxx_name | ✅ 关联名称（按业务需要） | ❌ 不需要 | ❌ 不需要 | ✅ 含义，内部转id | ✅ 关联名称 |
| xxx_code | ✅ 关联编码（按业务需要） | ❌ 不需要 | ❌ 不需要 | ✅ 含义，内部转id | ✅ 关联编码 |
| status | ✅ 状态值 | ✅ 状态值 | ❌ 不需要 | ✅ "启用"/"禁用" | ✅ 状态值 |
| status_text | ✅ 状态文字 | ❌ 不需要 | ❌ 不需要 | ❌ 不需要 | ✅ 状态文字 |

### 1.3 导入规则

**导入参数格式 = 创建接口参数**，默认使用含义（name/code），无需 id：

| 列名 | 填写内容 | 内部处理 |
|:-----|:---------|:---------|
| name | "管理员" | 直接存储 |
| xxx_name | "管理员" | 自动转 xxx_id |
| xxx_code | "ADMIN" | 自动转 xxx_id |
| status | "启用" | 自动转 1，"禁用"转 0 |

## 2. 模板设计标准（强制）

| 要求 | 说明 |
|:-----|:-----|
| 模板列名 | = 数据库字段含义，简短命名（如"名称"而非"名称字段"） |
| 模板列 | = 新增接口接收的参数（去除系统字段如id、create_time等） |
| 导出列 | = 模板列（保持对称） |
| 唯一约束 | 明确组合唯一字段，默认重复则失败；如需更新需用户明确说明 |
| 关联查询 | 填写code（如"US"），内部转ID |

---

## 3. 是/否字段规范（强制）

| 模板列名 | 导入填写 | 内部存储 |
|:---------|:---------|:---------|
| 是否启用 | "是" / "否" | 1 / 0 |
| 是否含税 | "是" / "否" | 1 / 0 |
| 是否必填 | "是" / "否" | 1 / 0 |

---

## 4. 关联字段回填逻辑（强制）

**识别规则**：

| 列名特征 | 匹配方式 | 说明 |
|:---------|:---------|:-----|
| 含"编码" | 查关联表的code字段 | 例：角色编码 → roles表code字段 |
| 含"名称" | 查关联表的name字段 | 例：角色名称 → roles表name字段 |
| 含"ID" | 直接使用填写值 | 例：角色ID → 直接作为ID |
| 其他 | 按关联表配置查找 | 默认规则 |

---

## 5. 导入响应格式（强制）

| 字段 | 类型 | 说明 |
|:-----|:-----|:-----|
| total | int | 总处理数 |
| success | int | 成功数 |
| fail | int | 失败数 |
| errors | array | 错误详情列表（最多10条） |

**错误详情格式**：

| 字段 | 类型 | 说明 |
|:-----|:-----|:-----|
| row | int | 失败行号 |
| message | string | 错误原因 |

---

## 6. 导入逻辑流程（强制）

**步骤**：
1. 检查文件存在和格式
2. 读取文件表头，映射到字段名
3. 逐行校验（必填/格式/是-否转换）
4. 关联字段回填（按列名特征自动识别）
5. 唯一性校验（重复则失败）
6. 事务提交
7. 返回结果（成功数/失败数/错误详情）

---

## 7. 导出逻辑流程（强制）

**步骤**：
1. 获取查询条件
2. 构建查询（支持单选/多选/范围查询）
3. 执行查询
4. 构建文件（导出列=模板列）
5. 返回文件下载

---

## 8. 文件格式与样式（强制）

### 8.1 文件格式

**默认使用Excel（.xlsx）**，同时支持CSV（.csv）。

| 格式 | 文件扩展名 | 样式支持 |
|:-----|:---------|:---------|
| Excel | .xlsx | 支持 |
| CSV | .csv | 不支持 |

### 8.2 Excel表头样式（强制）

| 属性 | 要求 |
|:-----|:-----|
| 字体加粗 | 是 |
| 文字水平对齐 | 居中 |
| 文字垂直对齐 | 居中 |

### 8.3 Excel表头批注（强制）

Excel模板的表头单元格应包含批注：

| 内容 | 说明 | 示例 |
|:-----|:-----|:-----|
| 类型 | 数据类型 | string/integer/date/enum |
| 示例 | 填写示例 | admin/2024-01-01/是 |
| 校验 | 合理性校验规则 | 长度6-20/邮箱格式 |
| 长度 | 最大长度或范围 | 最大20字符 |
| 必填 | 是否必填 | 必填/选填 |
| 枚举值 | 枚举值列表（可选） | 是,否/启用,禁用 |

### 8.4 文件命名规范（强制）

| 类型 | 命名格式 | 示例 |
|:-----|:---------|:-----|
| 导入模板 | {模块}_template.xlsx | role_template.xlsx |
| 导出文件 | {模块}_export_{日期}.xlsx | role_export_20240101.xlsx |
