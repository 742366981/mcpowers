# 定时任务规范

本文档定义定时任务的通用规范。

---

## 1. 概述

### 1.1 适用范围

| 语言/平台 | 状态 | 说明 |
|:----------|:-----|:-----|
| Python | ✅ 已支持 | 使用 APScheduler |
| Java | 🔜 规划中 | 预计 v2.0 支持 |
| Go | 🔜 规划中 | 预计 v2.0 支持 |

### 1.2 技术选型

| 组件 | 技术 | 说明 |
|:-----|:-----|:-----|
| 调度器 | APScheduler BackgroundScheduler | 后台定时任务调度 |
| 分布式锁 | Redis | 多进程环境下的任务互斥 |
| 执行器 | ThreadPoolExecutor | 线程池执行任务 |

## 2. 调度器配置

### 2.1 Python APScheduler

```python
scheduler = BackgroundScheduler(
    executors={
        'default': ThreadPoolExecutor(10)
    },
    job_defaults={
        'coalesce': False,
        'max_instances': 1
    }
)
```

### 2.2 App Context 包装器

定时任务在独立线程中执行，需要手动注入应用上下文：

```python
_app = None

def _job_wrapper(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        with _app.app_context():
            return func(*args, **kwargs)
    return wrapper


def init_scheduler(app):
    global _app
    _app = app
    scheduler.start()
```

## 3. 执行时间类型

| 类型 | 参数 | 示例 |
|:-----|:-----|:-----|
| cron | hour, minute, day | 每天凌晨2:00执行 |
| interval | minutes/hours/days | 每5分钟执行 |
| date | run_date | 特定日期执行 |

### 3.1 Cron表达式

```python
scheduler.add_job(func, 'cron', hour=2, minute=0)
scheduler.add_job(func, 'cron', day_of_week='mon-fri')
```

### 3.2 Interval表达式

```python
scheduler.add_job(func, 'interval', minutes=5)
scheduler.add_job(func, 'interval', hours=1)
```

## 4. 分布式锁（强制）

### 4.1 分布式锁实现

```python
class SchedulerLock:
    def __init__(self, lock_key, expire_seconds=300):
        self.lock_key = f'{self.LOCK_PREFIX}:{lock_key}'
        self.expire_seconds = expire_seconds

    def acquire(self):
        result = admin_redis.atomic_lock(self.lock_key, ex=self.expire_seconds)
        return result is not None and result != 0

    def release(self):
        admin_redis.delete(self.lock_key)

    def __enter__(self):
        return self.acquire()

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.release()
```

### 4.2 任务装饰器

```python
def with_scheduler_lock(lock_key, expire_seconds=3600):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            with SchedulerLock(lock_key, expire_seconds):
                return func(*args, **kwargs)
        return wrapper
    return decorator
```

### 4.3 使用示例

```python
@with_scheduler_lock('daily_cleanup', expire_seconds=3600)
def daily_cleanup():
    """
    每日清理任务示例

    执行时间: 每天凌晨2:00
    锁超时: 1小时
    """
    # 任务逻辑...
```

## 5. 注意事项

| 注意事项 | 说明 |
|:---------|:-----|
| 生产模式 | 定时任务仅在生产模式下启动 |
| app_context | 任务函数需要包装应用上下文 |
| 分布式锁 | 多进程部署时必须使用 `@with_scheduler_lock` 装饰器 |
| 锁超时 | 根据任务预估执行时间设置 `expire_seconds` |
| replace_existing | 使用 `replace_existing=True` 确保任务ID唯一 |
